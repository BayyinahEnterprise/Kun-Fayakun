## Title

furqan-lint vs. bandit: A Finding-Count Comparison Across 25 Python Codebases

## Description

Empirical benchmark of furqan-lint v2.1.0, a multi-language static analysis tool checking for structural honesty (surface-substrate divergence), against bandit 1.9.4 across 25 widely-used open-source Python packages (2.3M lines, 5,252 files). Includes raw JSON output from both tools, benchmark harness with offline replay, 208 tests, and a machine-readable rule manifest covering 50 rules across six languages (Python, C, C++, Java, C#, Ada/SPARK).
